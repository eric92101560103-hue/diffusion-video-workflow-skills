# 繁體中文字幕

## 使用範圍與設定優先順序

這是個人繁體中文字幕偏好，可套用到後續 Diffusion Studio 影片。以這次使用者指示優先，其次是目前專案中已調整的值，最後才是本技能的預設。套用單一修改時保留其他手動設定。

先用 Diffusion `context` 確認開啟的專案；從其入口 JSX 讀取字幕與場景設定。使用 Diffusion 工具前，閱讀安裝版本的 `/Applications/Diffusion Studio.app/Contents/Resources/docs/skills/editor.md`，以當地文件為 API 依據。素材、場景 ID 與字幕數量由目前專案取得，避免沿用舊專案的識別碼。

## 字幕文字與時間

- 使用繁體中文，保留原本口語、英文詞與意思；每次顯示一個語意段，以一行為主，必要時最多兩行。
- 每段字幕末尾移除標點符號，包含逗號、句號、問號、驚嘆號、冒號、分號與省略號；同時清理刪除後留下的末尾空格。保留句中標點與既有換行。可用 Unicode 標點類別辨識結尾，而非刪除整句內所有標點。
- 每段都是時間軸上可編輯的 `<text>`，收在「繁體中文字幕（可編輯）」sequence。文字與出現／結束時間各自獨立，外觀由整組控制。
- 調整樣式或標點時保留字幕的 ID、時間、影音剪輯與音軌；同步更新字幕物件名稱中的文字即可。既有轉錄稿與 SRT 只有在要求同步時才更新，避免用舊逐字稿蓋回畫面上已手動修改的字幕。
- 若需新轉錄，沿用已存在的轉錄快取。原專案偏好本機 whisper.cpp、Metal GPU、中文 zh、逐 token 時間，再人工斷句與繁體校正；這是轉錄偏好，不是每次改字幕都重跑的步驟。

## 預設外觀

完整數值與 35 項控制的快照在 [settings.json](references/settings.json)。需要套用或重建控制時讀取它。數值以 settings.json 的預設快照為準，現有專案中的手動調整優先。

| 項目 | 預設 |
| --- | --- |
| 字型、字級、字重 | Noto Sans TC、80 px、500、normal |
| 顏色、不透明度 | 白色 #FFFFFF、90% |
| 行距、字距 | 0.9 倍、0.5 px |
| 方格 | 1033 × 91 px；水平置中；Y = 1887 |
| 文字對齊 | 水平 center、垂直 bottom |
| 變形 | 旋轉 0；縮放 1；偏移 0 |
| 描邊 | 關閉；保留黑色、寬度 6、100%、round 的備用值 |
| 陰影 | 開啟；黑色；77%；模糊 0；距離 5；角度 −45° |
| 背景、動畫 | 無字幕背景、無逐字高亮與入出場動畫 |

座標以 1440 × 2560 直式畫面為基準：置中時 `x = (sceneWidth - subtitleWidth) / 2`，原尺寸即 203.5。Y 指字幕方格左上角的座標，不是文字基線；文字使用 bottom 對齊，兩行會向上延伸。保留使用者指定的換行並檢查文字有無超出畫面。

其他尺寸的影片以寬度比例換算尺寸與字級、以高度比例換算 Y，先檢查實際畫面；使用者指定絕對值時照其指定。保持水平置中，調整方格寬度後仍需重算 x。

陰影用 `offsetX = distance * cos(angle)`、`offsetY = -distance * sin(angle)`，角度先轉為弧度。整段 opacity 與陰影 opacity 為兩層設定；以最終 capture 為視覺依據。

## 整組共用控制

需要新增共用欄位時，參考 [shared-controls.tsx](references/shared-controls.tsx)。把宣告和元件複製到目前組合的同一個 JSX 檔；保留現有專案值，並將範例內 1440 換為實際場景寬度。範例是字幕樣式模板，不是完整影片專案。

- 用頂層 `const` 加 `@inspect`，初始值為字串、數字或布林 literal。每個字幕與它的 stroke、shadow 都引用這些控制；巡查全數字幕，清掉遺漏的硬編碼樣式。
- 按「繁體字幕／文字、排版、變形、外觀、描邊、陰影」分組，提供字型、字級、字重、字體樣式、文字顏色、行距、字距、英文大小寫、文字水平／垂直對齊、方格置中、X／Y、方格寬高、鎖定比例、旋轉、縮放、偏移、不透明度、混合模式、可見性，以及描邊和陰影各項控制。
- 衍生值直接寫在 JSX props 或元件內，確保滑桿即時連動。不要在模組頂層將 inspector 變數算成固定衍生常數，也不要跨檔 import 這些 inspector 變數。
- 單句內容與時間維持逐段控制；共用欄位中不放一個會把所有字幕內容或時間覆蓋掉的輸入框。鎖定方格比例是編輯器縮放手把的行為，不代表獨立寬高滑桿會自動聯動。

使用者操作說明：點畫布空白處，在右側「繁體字幕」各區塊調整，往下捲動可看到全部設定。全選的面板與這組自訂共用控制是不同入口；不要以全選時的欄位數推斷其是否可調。共用屬性也可能在單選的面板中改動時寫回共用變數，修改後確認受影響範圍。

## 驗證與匯出

每次修改後核對全數受影響字幕的設定，執行 Diffusion `check`。涉及外觀或位置時，以 `capture` 抽查前、中、後與兩行長句；確認字型、換行、置中與位置。需要確認右側控制面板時用 `screenshot`。以實際輸出為完成依據，工具短暫仍在重新編譯時等待最新來源可用再檢查。

只有使用者要求時匯出 MP4。沿用高畫質：原專案 1440 × 2560、30 fps、H.264/avc 24 Mbps、AAC 48 kHz 256 kbps。在 `package.json` 的 `diffusion.export.<實際sceneId>` 設定；`resolution` 是短邊 1440，不是直式影片高度。其他來源的尺寸與 fps 按當前專案與要求決定，避免盲目放大。

使用者要求存桌面時才寫桌面。要求新一版就使用新檔名；要求取代時確認指的是哪個既有匯出檔，在專案內先匯出並 probe 確認影像、音訊、時長與解析度，再取代指定檔案並核對檔案完整性。依當前工作區權限處理專案外寫入；本技能不給予額外覆寫或來源媒體刪除權限。

手動匯出入口（目前已驗證版本）：左上角專案下拉選單 → File → Export → Export scene…，快捷鍵 ⌘E。在儲存視窗以 ⌘⇧D 切到桌面；同名檔案依系統對話框決定是否取代。版本不同時以當前 UI 為準。
