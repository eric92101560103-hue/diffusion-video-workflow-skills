# Domain Docs

## Layout

本 repo 採 single-context：詞彙表使用根目錄 `GLOSSARY.md`，架構決策記錄使用 `docs/adr/`。

## Consumer rules

探索程式、撰寫規格或提出架構變更前，先閱讀已存在的 `GLOSSARY.md` 及與工作範圍相關的 ADR。
文件尚未存在時直接繼續；在釐清詞彙或形成決策時，由 domain-modeling 工作流程按需建立。
議題、規格、程式與測試沿用詞彙表中的術語。遇到缺詞時確認是否為既有概念，再記錄待釐清的詞彙。
提案若與既有 ADR 衝突，明確指出該 ADR 與重新討論的理由。
