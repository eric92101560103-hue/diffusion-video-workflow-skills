# 口播粗剪技能：已確認設計

狀態：設計已確認，技能第一版已建立；尚未實片驗收。2026-11-04。

## 使用者已提出的需求

使用者自行把完整原片匯入 Diffusion Studio，再於 Codex 對話使用可重用技能，讓 agent 先完成粗剪。此文件記錄已確認設計；技能已建立，但尚未核准或執行特定素材的粗剪。

## 既有背景與事實

- 同一個人工作流程已有繁體中文字幕與人工審核後匯出技能；本次新能力是前段粗剪，與現行原生排程功能分開設計。
- 工作區另有學術課程長片選段的歷史試驗。該試驗的素材、60–90秒限制、轉錄服務及逐次核准策略，不能自動套用到本次新技能。
- 訪談初期已由唯讀工具確認 Diffusion Studio 當時未開啟專案。這不影響先討論技能規格。
- 安裝版本的官方文件支援以影音來源起訖及明確播放時間組成可編輯粗剪；片段銜接時間需明確計算。內建轉錄會上傳音訊，不能稱作純本機轉錄；既有字幕技能優先使用本機 whisper.cpp 與既有快取。

## 決策樹：第一輪已確認

1. 第一版針對使用者自己拍攝的單人中文口播。
2. 粗剪保留原本敘事順序，刪除明顯講錯、重錄、重複句及過長空白；保留有意義的停頓、情緒與有效內容。精華選段、重組論述另行定義。
3. 使用者明確要求在當前已開啟的Diffusion專案中建立可編輯粗剪草稿，不要求另外開啟另一份專案。原片已存在電腦，維持原位置及內容。原片保存與剪輯編排保存不同；編輯前保存可還原的編排快照作為執行保護，不讓使用者另外管理專案。

已將「原片」與「粗剪草稿」定義記入根目錄GLOSSARY.md。這些是可逆工作流程選擇，尚無需另立ADR。

## 第二輪已確認

4. 腳本選填；提供時用來理解原意，允許自然口語及臨場補充，沒有腳本則依錄影內容判斷。
5. 重錄優先保留意思完整、表達清楚、語氣自然的版本，不固定選最後一次。不同版本意思有差異且無法確定取捨時，保留並標記給使用者。
6. 沒有敘事作用的空白，初始規則為超過1秒時縮短至約0.3–0.5秒；思考、情緒與強調停頓保留，首支實剪後可調整。此門檻不是把所有靜音一律切掉的指令。
7. 只刪明顯卡頓的「嗯、呃」、結巴及無意義重複；保留自然語氣與銜接語。
8. 第一版不設硬性秒數，保留完整有效內容；後續內容精簡由使用者另行決定。

## 第三輪已確認

9. 目前專案只有一支明確原片時直接處理；有多支候選影片時，先由使用者指定。
10. 第一版以尚未加入字幕、配樂及其他人工編排的口播為主。已有這些內容且未指定範圍時，先確認範圍，保留既有編排。
11. 沿用現有本機轉錄工具與有效快取；本機無法處理時先回報，需要雲端轉錄則另行確認，音訊預設留在本機。
12. 人工修改後的再次處理優先依指定問題局部修改；未指定範圍時先確認，只有明確要求整段重新粗剪才從原片重做。

使用者另指定名稱與適用範圍須明確標示「口播粗剪」。技能識別為 `diffusion-talking-head-rough-cut`，介面顯示名稱為「口播粗剪」。

## 技能交付與驗收

技能來源：[口播粗剪](../../skills/diffusion-talking-head-rough-cut/SKILL.md)。核心規則集中於技能文件，實作與後續使用以使用者當次指示優先。詞彙記錄於根目錄GLOSSARY.md；本輪沒有需額外ADR的架構取捨。

執行時核對目前專案、來源與修改範圍，保留原片及編排快照；保留區間必須可追溯到原片時間碼，影音同步、接點及workarea一致。結構／畫面檢查與音訊聽辨分開，能力不足時明列待審，不冒稱完整聽辨。交付目前專案內可編輯草稿、前後時長、刪剪摘要與需人工審閱的時間碼，讓使用者決定是否接受；本輪建立技能不自動授權粗剪任何未指定原片。

尚未進行真實原片試剪，停頓門檻與重錄取捨仍需首支實剪後依使用者回饋校準。原有Meta發布票據與定時驗收不在本次技能新增範圍。

技能已安裝至本機Codex技能目錄，原始版本保留於本repo；本輪未提交推送或更新發布plugin。格式與介面名稱檢查通過，另由獨立代理進行三個紙上情境試讀（原片初剪、人工修改後重跑、本機轉錄不可用），未進行真實剪輯。依試讀補明局部剪接導致字幕／配樂移位也須包含在確認範圍。
